# 1. ტექნიკური დავალება

**პროექტი:** Logistics Platform — B2B / B2C ლოჯისტიკური და ტრანსპორტირების პლატფორმა
**ფორმატი:** ინდივიდუალური პროექტი
**ვადა:** 7–10 ოქტომბერი, 2026
**ვერსია:** 1.0

---

## 1. პროექტის შერჩევა

სამი ვარიანტიდან (ლოჯისტიკა, WMS, სამედიცინო ჯავშნები) არჩეულია **ვარიანტი №1 — ლოჯისტიკური და ტრანსპორტირების პლატფორმა**.

**არჩევის დასაბუთება:**
- რეალური, ადვილად გასაგები ბიზნეს-სცენარი (საქართველოს ქალაქთაშორისი მარშრუტები, მაგ. თბილისი → ბათუმი);
- სამი განსხვავებული როლი, რაც RBAC-ს (როლებზე დაფუძნებული წვდომა) ნათლად აჩვენებს;
- ტექნიკური გამოწვევების ბალანსი: რუკა, ძებნა/ფილტრაცია, ტრანზაქციები, ფორმების ვალიდაცია;
- ერთი ადამიანის მიერ 4 დღეში MVP-ის რეალისტური მოცულობა.

## 2. პროექტის მიზანი

ვებ აპლიკაცია, სადაც გადამზიდები და კომპანიები ქმნიან მარშრუტებს, ხოლო მგზავრები/დამკვეთები (რეგისტრაციის გარეშეც) ეძებენ, ფილტრავენ და ჯავშნიან ადგილებს.

## 3. მომხმარებლის როლები

| როლი | კოდი | აღწერა |
|---|---|---|
| სტუმარი / ფიზიკური პირი | `guest` | რეგისტრაციის გარეშე ეძებს და ჯავშნის მარშრუტს |
| მძღოლი / გადამზიდი | `provider` | ქმნის მარშრუტებს, მართავს ფასს, ადგილებს და შემოსავალს |
| იურიდიული პირი / კომპანია | `company` | მართავს კომპანიის პროფილს, ბიუჯეტს, მძღოლებს და კორპორატიულ რეისებს |

### წვდომის მატრიცა (RBAC)

| ფუნქცია | guest | provider | company |
|---|:---:|:---:|:---:|
| მარშრუტების ძებნა და ფილტრაცია | ✅ | ✅ | ✅ |
| ექსპრეს ჯავშანი | ✅ | ✅ | ✅ |
| მარშრუტის შექმნა / რედაქტირება | ❌ | ✅ (საკუთარი) | ✅ (კომპანიის) |
| ბალანსის შევსება | ❌ | ✅ | ✅ |
| შემოსავლების ისტორია | ❌ | ✅ | ✅ |
| კომპანიის პროფილი და ბიუჯეტი | ❌ | ❌ | ✅ |
| მძღოლების მართვა | ❌ | ❌ | ✅ |
| Dashboard / Settings | ❌ | ✅ | ✅ |

## 4. ფუნქციური მოთხოვნები

### 4.1 ავტორიზაცია და როლები (Epic E4)
- FR-01: რეგისტრაცია როლის არჩევით (`provider` / `company`)
- FR-02: შესვლა / გასვლა, სესიის შენახვა
- FR-03: სტუმრის რეჟიმი რეგისტრაციის გარეშე
- FR-04: დაცული მარშრუტები (route guards) როლის მიხედვით; უფლების არქონისას გადამისამართება

### 4.2 მარშრუტების მართვა — Provider (Epic E5)
- FR-05: მარშრუტის შექმნა: საიდან, სად, თარიღი, დრო, ტევადობა (ადგილები), ფასი
- FR-06: საკუთარი მარშრუტების სია, რედაქტირება, წაშლა
- FR-07: ფორმის ვალიდაცია (React Hook Form + Zod): თარიღი წარსულში არ იყოს, ადგილები > 0, ფასი > 0, „საიდან“ ≠ „სად“

### 4.3 ძებნა და ჯავშანი — Guest (Epic E6)
- FR-08: ძებნა მიმართულებით (საიდან / სად)
- FR-09: ფილტრები: თარიღი, ფასის დიაპაზონი; სორტირება ფასით/დროით
- FR-10: ფილტრები ინახება URL-ში (გაზიარებადი ძებნა)
- FR-11: ადგილების არჩევა და ექსპრეს ჯავშანი (სახელი, ტელეფონი)
- FR-12: overbooking-ის პრევენცია — ჯავშნისას თავისუფალი ადგილები მცირდება, 0-ზე ჯავშანი იბლოკება
- FR-13: ჯავშნის დადასტურების გვერდი კოდით

### 4.4 ბალანსი და ტრანზაქციები (Epic E7)
- FR-14: ბალანსის შევსების იმიტაცია (ფორმა თანხით, რეალური გადახდის გარეშე)
- FR-15: ჯავშნისას თანხის ჩარიცხვა provider-ის ბალანსზე
- FR-16: ტრანზაქციების ისტორია (ტიპი, თანხა, თარიღი)

### 4.5 კორპორატიული კლიენტი (Epic E8)
- FR-17: კომპანიის პროფილი (სახელი, საიდენტიფიკაციო კოდი, საკონტაქტო)
- FR-18: ბიუჯეტის ლიმიტი და ხარჯის კონტროლი
- FR-19: მძღოლების დამატება / სია, კორპორატიული რეისების მიბმა მძღოლზე

### 4.6 რუკა (Epic E9)
- FR-20: მარშრუტის ჩვენება ინტერაქტიულ რუკაზე (react-leaflet + OpenStreetMap)
- FR-21: ქალაქების მარკერები და საწყისი/საბოლოო წერტილის ხაზი

## 6. არქიტექტურა

```
exam-project/
├── index.html          ← პორტალის გვერდი (Git მოდულის დავალება)
├── README.md
├── docs/               ← ეს დოკუმენტაცია
└── app/                ← React (Vite) აპლიკაცია
    └── src/
        ├── app/        ← router, providers, layout
        ├── features/
        │   ├── auth/
        │   ├── routes/
        │   ├── booking/
        │   ├── balance/
        │   ├── company/
        │   └── map/
        ├── components/ ← საერთო UI კომპონენტები
        ├── pages/
        └── lib/        ← mock API, RBAC helpers, utils
```

**Backend:** mock სერვისების ფენა localStorage-ზე. ყველა მოთხოვნა გადის `lib/api/*` ფუნქციებზე (async, დაყოვნების იმიტაციით), რათა მომავალში რეალურ API-ზე გადასვლა მხოლოდ ამ ფენის შეცვლას მოითხოვდეს.

### მონაცემთა მოდელი

| ერთეული | ველები |
|---|---|
| `User` | id, name, email, password (mock), role, balance, companyId? |
| `Company` | id, name, taxId, contact, budgetLimit, spent |
| `Driver` | id, companyId, name, phone |
| `Route` | id, ownerId, driverId?, from, to, date, time, capacity, seatsLeft, price |
| `Booking` | id, routeId, passengerName, phone, seats, total, code, createdAt |
| `Transaction` | id, userId, type (`topup` / `earning` / `spend`), amount, createdAt |
