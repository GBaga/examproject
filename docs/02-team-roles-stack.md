# 2. გუნდი, როლები და ტექნოლოგიური სტეკი

## 1. გუნდი და როლები

**ფორმატი:** ინდივიდუალური პროექტი — 1 წევრი (გოგა).
ინდივიდუალურ პროექტში ყველა როლი ერთ ადამიანს აქვს, მაგრამ პასუხისმგებლობები გამიჯნულია, რათა თითოეული სამუშაო მიმართულება ცალკე დაიგეგმოს და შემოწმდეს.

| როლი | პასუხისმგებლობა | შედეგი |
|---|---|---|
| **Project Manager / ლიდერი** | დაგეგმვა, Jira დაფა, ვადების კონტროლი, რისკების მართვა | Jira `LOG`, Timeline, რისკების რეესტრი |
| **Solution Architect** | არქიტექტურა, მონაცემთა მოდელი, ფოლდერების სტრუქტურა, RBAC | ტექნიკური დავალება, `lib/` ფენა |
| **UI/UX დიზაინერი** | გვერდების სტრუქტურა, ნავიგაცია, responsive დიზაინი | Layout, კომპონენტები, Tailwind სტილი |
| **Frontend Developer** | ფუნქციონალის იმპლემენტაცია | `features/*` |
| **QA** | ტესტირება როლების მიხედვით, ბაგების აღრიცხვა | Jira Bug Issues, საბოლოო შემოწმება |
| **DevOps** | Git workflow, Vercel deploy | GitHub რეპო, საჯარო URL |

## 2. ტექნოლოგიური სტეკი

| ფენა | ტექნოლოგია | რატომ |
|---|---|---|
| Build | **Vite** | სწრაფი dev server და build |
| UI ბიბლიოთეკა | **React 19** | სილაბუსის ძირითადი ტექნოლოგია |
| სტილი | **Tailwind CSS** | სწრაფი, თანმიმდევრული სტილი, responsive utilities |
| მარშრუტიზაცია | **React Router** | გვერდები, დაცული მარშრუტები (route guards) |
| State მართვა | **Zustand** | მსუბუქი გლობალური state (auth, balance) |
| ფორმები | **React Hook Form** | ეფექტური ფორმები ზედმეტი რენდერების გარეშე |
| ვალიდაცია | **Zod** | სქემაზე დაფუძნებული ვალიდაცია |
| რუკა | **react-leaflet + OpenStreetMap** | უფასო, API key არ სჭირდება |
| Backend | **Mock API (localStorage)** | ტრანზაქციების იმიტაცია, სერვერის გარეშე |
| ხატულები | **lucide-react** | მსუბუქი SVG ხატულები |

## 5. Jira ↔ GitHub კავშირი

React-ის ბრანჩებში და კომიტებში იწერება Jira Issue-ს გასაღები:

```
ბრანჩი:  feature/LOG-24-auth-rbac
კომიტი:  LOG-25 Add role-based route guards
```

> ⚠️ **გამონაკლისი:** Git მოდულის ბრანჩები (`feature-header`, `nav-feature`, `nav-alt`) და კომიტები იწერება **ზუსტად** დავალების ინსტრუქციის მიხედვით, Jira key-ის გარეშე. დეტალები: [05-git-workflow.md](./05-git-workflow.md).
